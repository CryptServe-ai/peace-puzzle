# Picture of peace — 5 × 5 puzzle

Open index.html in a web browser to play. It contains the image, styles, and game code, and works offline without installation.

The board uses 5 columns, 5 rows, 4 px gaps, and 4 px outer padding. Drag one tile onto another to swap them, or click/tap two tiles. Keyboard users can focus a piece, use arrow keys, and press Enter/Space to select. Shuffle starts a new game. Show picture reveals the reference. The timer starts on the first swap. Completing the puzzle removes the gaps to display the full artwork.

## Host on GitHub Pages

1. Sign in to GitHub and create a public repository, for example `peace-puzzle`.
2. Upload `index.html` directly to the repository root (not inside a subfolder) and commit it to the `main` branch. No other files are required.
3. Open the repository's Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/(root)`, then click Save.
6. Wait for deployment to finish. Pages settings will show the published URL, typically `https://YOUR-USERNAME.github.io/peace-puzzle/`.
7. To update the game, replace index.html and commit again.

If the site gives a 404, check that index.html is lowercase and at the selected branch root, and check the repository Actions tab for deployment status.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
